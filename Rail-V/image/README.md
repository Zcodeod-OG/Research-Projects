# Image branch

Pretrained vision model fine-tuned on public rail defect images, the image half of the
fused model in the [plan](../APPROACH.md). Work in progress: first step is learning the
layout of the downloaded sets.

| Script | What it does |
| --- | --- |
| `inspect_images.py --data DATA` | Folders, image counts, sizes and zip contents of the image sets (`rsdds`, `kaggle_track_faults`, ...). |
